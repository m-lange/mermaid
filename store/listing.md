### Short description (summary, max. 100 characters)

```text
Insert and edit Mermaid diagrams and charts in Word, Excel and PowerPoint – with live preview.
```

### Long description (HTML)

```html
<p>Create flowcharts, sequence diagrams, Gantt charts, mind maps and many more diagrams from simple text – right inside Word, Excel and PowerPoint. Mermaid Editor uses the open-source Mermaid diagram language: write a few lines of code and the diagram appears in your document.</p>
<p><b>Features</b></p>
<ul>
<li><b>35 diagram and chart types</b>: flowchart, sequence, class, state, entity relationship (ER), Gantt, pie, mind map, timeline, git graph, C4, architecture, block, Kanban, user journey, quadrant, XY, Sankey, radar, treemap – plus the new Mermaid 12 types such as Venn, Ishikawa (fishbone), Wardley map, swimlane and more.</li>
<li><b>Code editor</b> with syntax highlighting, auto-completion and a toolbar of code building blocks (snippets) for the selected diagram type.</li>
<li><b>Live preview directly in the document</b> while you type. <b>Save</b> keeps your changes, <b>Cancel</b> restores the last saved version.</li>
<li><b>Edit later</b>: select a diagram in the document and the editor shows its code again. All diagrams of a document are listed in the task pane.</li>
<li><b>Matches your Office theme</b>: colors and font can follow the document theme (Background 2 fills, Text 2 lines, Text 1 text, body font, accent colors for data series). Further themes, a hand-drawn look and background options are available.</li>
<li>User interface in <b>English and German</b>.</li>
</ul>
<p><b>Supported apps</b>: Word, Excel and PowerPoint (Microsoft 365 on Windows and Mac, and Office on the web).</p>
<p><b>Privacy-friendly</b>: everything runs locally in the task pane. Diagrams are rendered on your device with the open-source Mermaid library. The diagram code is stored only inside your document (and in the image's alt text); the diagram is inserted as a PNG image. No account, no sign-in, no tracking, no telemetry, no cookies – no data is sent to the developer.</p>
<p><b>Free and open source</b>: licensed under GPL-3.0. Source code, issue tracker and support: github.com/m-lange/mermaid.</p>
<p><i>This add-in is an independent project. It is not affiliated with, sponsored or endorsed by the Mermaid project or Microsoft. Microsoft, Word, Excel, PowerPoint and Office are trademarks of the Microsoft group of companies.</i></p>
```

## Notes for certification (for Microsoft reviewers)

```text
Mermaid Editor for Word, Excel & PowerPoint – notes for certification

No sign-in, account, license key or test credentials are required. The add-in has no backend:
all rendering happens locally in the task pane with the open-source Mermaid library. Static files
are hosted on GitHub Pages (https://m-lange.github.io/mermaid/); Office.js is loaded from
appsforoffice.microsoft.com. No data is sent to the developer.

How to test (Word, Excel or PowerPoint):
1. Open a new document/workbook/presentation. On the Insert tab, click "Mermaid Diagram" in the
   "Mermaid" group. The task pane opens.
2. Click a diagram type (e.g. "Flowchart"). An example diagram is inserted into the document as a
   PNG image and the code editor opens.
3. Edit the code (e.g. rename a node). With valid code, the image in the document updates live
   after a short delay (live preview in the document). The eye icon switches to a preview inside
   the task pane instead.
4. Click "Save" to keep the changes, or "Cancel" to restore the last saved version.
5. Select the inserted diagram in the document: the editor opens again with its code (re-edit).
   All diagrams of the document are also listed in the task pane.
6. Toolbar above the editor: theme (incl. "Document" = Office theme), look (classic/hand-drawn),
   background, and code building blocks (snippets) for the current diagram type.

Office theme: in Word or PowerPoint, change the theme on the Design tab, then open the theme
menu in the add-in's toolbar and choose "Re-read theme from document". The editor offers to
update the diagram to the new colors and font. (Excel approximates the theme from cell styles.)

The UI language follows the Office display language (English or German).

Supported API sets / requirements:
- Word: WordApi 1.3 required, WordApi 1.4 recommended.
- Excel: ExcelApi 1.9 required. Automatic detection of a selected diagram (shape selection) needs
  ExcelApi 1.19; on older builds, open a diagram for editing from the list in the task pane.
- PowerPoint: PowerPointApi 1.7 required; PowerPointApi 1.8 for in-place updates of diagrams.

Known behavior: each live update in the document creates an undo step in Office. The theme font
must be installed locally; otherwise a fallback font is used.

Support: https://github.com/m-lange/mermaid/issues
Source code (GPL-3.0-only): https://github.com/m-lange/mermaid
```

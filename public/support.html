Support

Mermaid Editor for Word, Excel & PowerPoint

Get help

Questions, bug reports and feature requests are handled via GitHub Issues. A free GitHub account is required to open an issue.

Open GitHub Issues

Please include in your report:

  • the Office application (Word, Excel or PowerPoint),
  • the platform (Windows, Mac or Office on the web) and the Office version/build (File > Account > About),
  • the Mermaid code of the affected diagram,
  • a screenshot of the problem and any error message shown in the task pane,
  • the steps to reproduce the problem.

Please do not post confidential content. Issues on GitHub are public – remove or replace sensitive text in diagram code and screenshots before posting.

Getting started

  1. Open the Insert tab and click Mermaid Diagram in the Mermaid group. The task pane opens.
  2. Click a diagram type (for example Flowchart, Sequence diagram or Pie chart). A small example is inserted into your document.
  3. Edit the code in the editor. The diagram in the document updates live while you type (only when the code is valid).
  4. Use the toolbar above the editor to change the theme, look and background, or to insert code building blocks for the current diagram type.
  5. Click Save to keep your changes, or Cancel to restore the last saved version.
  6. To edit a diagram later, select it in the document and open the task pane – the editor shows its code. All diagrams of the document are also listed in the task pane.

Syntax reference for all diagram types: Mermaid documentation (external website of the independent Mermaid project).

Frequently asked questions

Which Office applications and platforms are supported?

Word, Excel and PowerPoint in Microsoft 365 on Windows and Mac, and in Office on the web. The add-in needs these Office JavaScript API versions; older Office versions that do not support them cannot load it:

ApplicationRequiredRecommended / for all features
WordWordApi 1.3WordApi 1.4
ExcelExcelApi 1.9ExcelApi 1.19 (detect a selected diagram automatically; otherwise open it from the list in the task pane)
PowerPointPowerPointApi 1.7PowerPointApi 1.8 (update diagrams in place)

Can I still edit a diagram after copying it into another document?

Yes, in most cases. The diagram's code is stored in the document and additionally in the alt text of the image. If the stored data is missing (for example after copying the image into another document), the add-in recovers the code from the alt text and asks you to save it again. Alt text is limited, so very long code (more than about 4,000 characters) may be truncated.

How do the Office theme colors work?

With the theme Document (default), colors and font follow the document's Office theme: Background 2 for fills, Text 2 for lines and borders, Text 1 for text, the theme's body font, and Accent 1–6 for data series. If you change the design (for example on the Design tab in Word or PowerPoint), open the theme menu in the toolbar and choose Re-read theme from document; the editor then offers to update the diagram. Existing diagrams are never changed silently. Other themes (Default, Neutral, Forest, Dark, Base) are available as well.

Where is my diagram code stored?

Only inside your document: in a Custom XML Part and in the alt text of the inserted PNG image. Nothing is uploaded or sent to the developer. See the privacy policy.

Known limitations

  • The theme font must be installed on your computer; otherwise a fallback font (for example Segoe UI) is used for the diagram.
  • Each live update of the diagram in the document is a separate undo step in Office. If you prefer, switch the preview to the task pane (eye icon); the document then only changes when you save.
  • The inserted diagram is a PNG image. Edit it with the add-in, not with Office's picture tools.
  • Excel uses an approximation of the document theme (cell styles), and some features depend on the API versions listed above.
  • Some Mermaid features are not available (for example external icon packs and the ZenUML plugin).

Is this an official Mermaid or Microsoft product?

No. This add-in is an independent open-source project by Martin Lange. It uses the open-source Mermaid library but is not an official product of the Mermaid project, and it is not affiliated with or endorsed by Microsoft.

Where is the source code?

Hilfe erhalten

Fragen, Fehlermeldungen und Verbesserungsvorschläge werden über GitHub Issues bearbeitet. Zum Anlegen eines Issues ist ein kostenloses GitHub-Konto nötig.

GitHub Issues öffnen

Bitte geben Sie in Ihrer Meldung an:

  • die Office-Anwendung (Word, Excel oder PowerPoint),
  • die Plattform (Windows, Mac oder Office im Web) und die Office-Version/Build (Datei > Konto > Info),
  • den Mermaid-Code des betroffenen Diagramms,
  • einen Screenshot des Problems und ggf. die Fehlermeldung im Aufgabenbereich,
  • die Schritte, mit denen sich das Problem nachvollziehen lässt.

Bitte keine vertraulichen Inhalte veröffentlichen. Issues auf GitHub sind öffentlich – entfernen oder ersetzen Sie sensible Texte im Diagrammcode und in Screenshots vor dem Absenden.

Erste Schritte

  1. Öffnen Sie die Registerkarte Einfügen und klicken Sie in der Gruppe Mermaid auf Mermaid-Diagramm. Der Aufgabenbereich wird geöffnet.
  2. Klicken Sie auf einen Diagrammtyp (z. B. Flussdiagramm, Sequenzdiagramm oder Kreisdiagramm). Ein kleines Beispiel wird in das Dokument eingefügt.
  3. Bearbeiten Sie den Code im Editor. Das Diagramm im Dokument wird während der Eingabe laufend aktualisiert (nur bei gültigem Code).
  4. Über die Symbolleiste oberhalb des Editors ändern Sie Design, Darstellung und Hintergrund oder fügen Code-Bausteine für den aktuellen Diagrammtyp ein.
  5. Klicken Sie auf Speichern, um die Änderungen zu übernehmen, oder auf Abbrechen, um den zuletzt gespeicherten Stand wiederherzustellen.
  6. Um ein Diagramm später zu bearbeiten, markieren Sie es im Dokument und öffnen den Aufgabenbereich – der Editor zeigt seinen Code. Alle Diagramme des Dokuments werden außerdem im Aufgabenbereich aufgelistet.

Syntax aller Diagrammtypen: Mermaid-Dokumentation (externe Website des unabhängigen Mermaid-Projekts, englisch).

Häufige Fragen

Welche Office-Anwendungen und Plattformen werden unterstützt?

Word, Excel und PowerPoint in Microsoft 365 unter Windows und Mac sowie in Office im Web. Das Add-in benötigt folgende Versionen der Office-JavaScript-API; ältere Office-Versionen ohne diese Unterstützung können es nicht laden:

AnwendungMindestensEmpfohlen / für alle Funktionen
WordWordApi 1.3WordApi 1.4
ExcelExcelApi 1.9ExcelApi 1.19 (ausgewähltes Diagramm wird automatisch erkannt; sonst über die Liste im Aufgabenbereich öffnen)
PowerPointPowerPointApi 1.7PowerPointApi 1.8 (Diagramme an Ort und Stelle aktualisieren)

Kann ich ein Diagramm nach dem Kopieren in ein anderes Dokument noch bearbeiten?

Ja, in den meisten Fällen. Der Code wird im Dokument und zusätzlich im Alternativtext des Bildes gespeichert. Fehlen die gespeicherten Daten (z. B. nach dem Kopieren des Bildes in ein anderes Dokument), stellt das Add-in den Code aus dem Alternativtext wieder her und bittet Sie, erneut zu speichern. Der Alternativtext ist begrenzt; sehr langer Code (mehr als ca. 4.000 Zeichen) kann daher abgeschnitten sein.

Wie funktionieren die Farben des Office-Designs?

Mit dem Design Dokument (Standard) übernehmen Farben und Schrift das Office-Design des Dokuments: Hintergrund 2 für Füllungen, Text 2 für Linien und Rahmen, Text 1 für Texte, die Textkörper-Schriftart des Designs und Akzent 1–6 für Farbreihen. Wenn Sie das Design ändern (z. B. auf der Registerkarte Entwurf bzw. Design in Word oder PowerPoint), öffnen Sie in der Symbolleiste das Design-Menü und wählen Design aus Dokument neu einlesen; der Editor bietet dann an, das Diagramm zu aktualisieren. Bestehende Diagramme werden nie unbemerkt geändert. Zusätzlich gibt es weitere Designs (Standard, Neutral, Wald, Dunkel, Basis).

Wo wird mein Diagrammcode gespeichert?

Ausschließlich in Ihrem Dokument: in einer Custom XML Part und im Alternativtext des eingefügten PNG-Bildes. Es wird nichts hochgeladen oder an den Entwickler gesendet. Siehe Datenschutzerklärung.

Bekannte Einschränkungen

  • Die Schriftart des Designs muss auf Ihrem Computer installiert sein; andernfalls wird für das Diagramm eine Ersatzschrift (z. B. Segoe UI) verwendet.
  • Jede Live-Aktualisierung des Diagramms im Dokument ist in Office ein eigener Rückgängig-Schritt. Alternativ können Sie die Vorschau in den Aufgabenbereich verlegen (Augen-Symbol); das Dokument ändert sich dann erst beim Speichern.
  • Das eingefügte Diagramm ist ein PNG-Bild. Bearbeiten Sie es mit dem Add-in, nicht mit den Bildtools von Office.
  • Excel verwendet eine Näherung des Dokumentdesigns (Zellenformatvorlagen); einige Funktionen hängen von den oben genannten API-Versionen ab.
  • Einige Mermaid-Funktionen sind nicht verfügbar (z. B. externe Icon-Pakete und das ZenUML-Plugin).
